#  Console-Based User Login System

A basic user authentication and password management simulation built with Python, utilizing control flows, conditional logic, and loop structures.

---

## 🇬🇧 English Description

###  About The Project
This project is a console-based user authentication system developed in Python to practice control structures (`while`, `if-elif-else`) and user interaction (`input`).

The application verifies user credentials, provides interactive prompts on failed login attempts, and allows dynamic password updates during runtime.

###  Key Features
- **User Authentication:** Validates username and password credentials against stored variables.
- **Dynamic Loop Control:** Keeps prompting for input using a `while` loop until a successful login occurs.
- **Interactive Error Handling:**
  - Displays specific error messages for incorrect username or password.
  - Offers an option to reset the password when an incorrect password is entered.
- **Runtime Password Update:** Dynamically updates the user password in memory, allowing immediate use for subsequent login attempts.
- **Simulated Processing Delays:** Uses `time.sleep()` to simulate real-world credential checks and update procedures.

###  Built With
- **Language:** Python 3.x
- **Standard Library Modules:** `time`

## 🇹🇷 Türkçe Açıklama

###  Proje Hakkında
Bu proje, Python programlama dilinde kontrol yapılarını (`while`, `if-elif-else`) ve kullanıcı etkileşimini (`input`) pekiştirmek amacıyla geliştirilmiş konsol tabanlı bir kullanıcı giriş sistemidir.

Sistem, kullanıcının girdiği bilgileri kontrol eder, hatalı denemelerde kullanıcıya yönlendirici seçenekler sunar ve çalışma anında şifre güncellemesine olanak tanır.

###  Öne Çıkan Özellikler
- **Kimlik Doğrulama:** Kullanıcı adı ve şifrenin eşleşme kontrolü.
- **Dinamik Döngü Yapısı:** Başarılı giriş yapılana kadar kullanıcıdan girdi isteyen `while` döngüsü.
- **Akıllı Hata Yönetimi:**
  - Kullanıcı adı veya şifre hatalı olduğunda spesifik uyarı mesajları.
  - Şifre hatalı girildiğinde kullanıcıya şifresini yenileme seçeneği sunulması.
- **Canlı Şifre Güncelleme:** Kullanıcı şifresini değiştirdiğinde, yeni şifre anlık olarak değişkene atanır ve bir sonraki denemede geçerli olur.
- **Zaman Gecikmesi Simülasyonu:** `time.sleep()` kullanılarak gerçekçi bilgi kontrolü ve şifre değiştirme bekleme süreleri.

###  Kullanılan Teknolojiler
- **Dil:** Python 3.x
- **Modüller:** `time`
